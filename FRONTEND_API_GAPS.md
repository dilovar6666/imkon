# Недостающие API для Frontend IMKON

`GET /api/v1/vacancies/{id}` добавлен в текущем этапе: детали и отклик теперь работают с прямой ссылкой. Остальные ограничения ниже не подменяются демонстрационными результатами.

| Возможность | Нужный контракт | Где нужна | Текущее ограничение |
| --- | --- | --- | --- |
| Публичный профиль работодателя | `GET /employers/{id}` с названием, страной, признаком проверки | Карточка и детальная страница вакансии | `VacancyOut` содержит только `employer_id`; название не выводится по догадке. |
| Пагинация админ-очередей | `skip`/`limit` и `total` для списков пользователей и заявок | `/admin` | На накопленной тестовой БД страница становится чрезмерно длинной; UI не показывает выдуманное число страниц. |
| Мои вакансии работодателя | `GET /vacancies/mine` с черновиками, статусами и пагинацией | Кабинет работодателя | После перезагрузки нельзя показать созданные черновики и выбрать вакансию для работы с кандидатами. |
| Кандидаты и Kanban | Существующий `GET /applications/vacancies/{id}` дополнить безопасным кратким профилем/резюме кандидата; нужен список своих вакансий | Кабинет работодателя | Статусы откликов есть в API, но нет достаточных разрешённых данных для карточек кандидатов. |
| HR-менеджеры | Список, приглашение и отзыв участников организации с ролью `hr_manager` | Настройки работодателя | Модель членства есть, управляющего API пока нет. |
| Расширенный поиск | `total`, сортировка и фильтры по навыкам, стране, условиям, проверке работодателя | Каталог вакансий | Сейчас работают текст, зарплата от, валюта, график, опыт, язык и `skip`/`limit`; точное число страниц неизвестно. |
| Обучение | Курсы, уроки, прогресс, тесты и сертификаты | `/learn` и будущие страницы уроков | Каталог курсов и результаты обучения не создаются без Backend. |
| Gemini | Диалоги, сообщения, лимиты и безопасные контекстные действия | `/ai`, вакансии, резюме | Поле диалога отключено; ответы не имитируются. |
| Чат и уведомления | REST-история и WebSocket/notification contract | Кабинеты и будущий inbox | Нет отправки сообщений и центра уведомлений. |
| Избранное и отзывы | CRUD избранного и отзывов | Каталог и кабинет | Кнопки не показываются как рабочие. |
| Безопасная долгоживущая сессия | HttpOnly refresh-cookie, rotation и CSRF-контракт | Авторизация | Refresh JWT хранится только в памяти вкладки; после reload старую refresh-сессию клиент отозвать уже не может. |
| Production email | SMTP или проверенный почтовый провайдер, отправка кода и повторная отправка с лимитом | Регистрация | Development-код показывается только в dev; production-доставка ещё не настроена. |
